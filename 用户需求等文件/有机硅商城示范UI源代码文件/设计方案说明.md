# 有机硅商城 · UI 设计规范（最终版 V23）

> 本文档是「有机硅商城示范 UI」的**最终定稿规范**，与 `index.html`（首页）、`news.html`（信息资讯页）两个定稿文件完全对应。
> **所有后续新增/优化页面，必须遵循本规范的风格、组件与交互模式**，保证全站视觉与体验一致。

---

## 一、设计定位

- 面向「有机硅电商综合服务平台」的 B2B 电商平台 UI。
- 视觉基调：**蓝白体系**（与小程序「硅源智链」同源），明亮、干净、专业。
- 信息原则：**内容零删减、只重组展现**——列表类信息平铺展示，长列表用折叠，不藏核心信息。
- 商业原则：**广告位（首页轮播、名企推荐位）是核心，永远占据首屏最强曝光位**。

## 二、设计 Token（全局变量，新页面按需引用）

```css
:root{
  /* 品牌 */
  --blue:#2468F2;        /* 品牌亮蓝：主按钮、链接、选中态 */
  --blue-deep:#1443B8;   /* 深蓝：按钮 hover */
  --blue-ink:#123C8F;    /* 白卡上的深蓝大数字（价格/数据） */
  --grad-blue:linear-gradient(135deg,#1D4FD7 0%,#2F6FE8 55%,#3F86F9 100%); /* 行情卡/广告/Logo 底 */
  --grad-navy:linear-gradient(180deg,#1746C0,#12379A);  /* 分类竖栏深蓝 */

  /* 背景 & 卡片 */
  --bg:#F3F6FB;          /* 页面底色：浅灰蓝 */
  --surface:#FFFFFF;     /* 卡片纯白，大圆角 + 轻阴影，不用重描边 */

  /* 文字 */
  --ink:#13294B;         /* 主文字（深蓝黑） */
  --ink-2:#5A6B85;       /* 次文字 */
  --ink-3:#98A5BC;       /* 弱文字/占位符 */

  /* 语义色（国内行情惯例：红涨绿跌） */
  --up:#F04B3E;          /* 涨 / 强调价格 */
  --down:#14B968;        /* 跌 */
  --flat:#98A5BC;        /* 持平 */

  --line:#E9EEF6;        /* 分隔线/描边 */

  /* 圆角 */
  --r-md:12px; --r-lg:16px; --r-xl:20px;   /* 卡片统一 12~20px 大圆角 */

  /* 阴影（克制，不用重投影） */
  --shadow-card:0 2px 14px rgba(19,41,75,.06);
  --shadow-pop:0 10px 30px -8px rgba(36,104,242,.22);  /* 主按钮/主卡 */

  /* 版心 */
  --maxw:1280px;

  /* 字体 */
  --font-sans:"PingFang SC","Hiragino Sans GB","Microsoft YaHei","Source Han Sans SC","Noto Sans SC",-apple-system,sans-serif;
}
```

**数字规范**：所有价格、行情、统计数据使用等宽数字 `font-variant-numeric:tabular-nums`。

**禁用**：纯黑 #000 文字、纯紫渐变、重投影、细碎小圆角（<8px 卡片）。

## 四、核心组件规范

### 4.1 卡片

- 白底、`--r-lg` 16px 圆角、`--shadow-card` 轻阴影；**不用粗描边**。
- Hover：`translateY(-4px)` + `--shadow-pop`，只动 transform。
- **同一行内的卡片必须等高**（grid `align-items:stretch`），卡片底部操作行 `margin-top:auto` 推底，保证底边齐平。

### 4.2 按钮

| 类型          | 样式                    | 用途           |
| ----------- | --------------------- | ------------ |
| `--primary` | 蓝底白字 + `--shadow-pop` | 免费发布、搜全站、主操作 |
| `--ghost`   | 浅灰底 `#EFF3F9`         | 登录、次操作       |
| `--tint`    | 浅蓝底 `#EEF4FF` 蓝字      | 企业入驻         |
| 橙钮          | `--up` 底白字            | 「联系方式」等转化按钮  |
| 描边胶囊        | 1px `--line` 圆角100px  | 关注 / 留言      |

- 操作行按钮**等宽排列**（`flex:1`），描边与实底组合。

### 4.3 Tabs / Chips（三种形态，按场景使用）

| 形态       | 样式                  | 场景             |
| -------- | ------------------- | -------------- |
| 文字+短下划线  | 菜单=蓝线，品种=红线(`--up`) | 导航菜单、行情品种 Tab  |
| 蓝色胶囊     | 选中蓝底白字圆角 9px        | 月份切换、分类 chips  |
| 浅灰 chips | 选中蓝底白字圆角100px       | 筛选标签（原料区/硅油区…） |

### 4.4 图表（行情走势）

- 优先 ECharts；设计稿用 SVG 时 **viewBox 尺寸必须接近实际渲染尺寸**（禁止 `preserveAspectRatio="none"` 拉伸，否则文字变形）。
- 折线 `#2468F2` 2.5px + 8% 透明度面积填充；网格线 `#EDF1F8`。
- 左轴价格：涨红 / 中间黑 / 跌绿；右轴百分比：正红 `+6.47%`、零灰 `+0.00%`、负绿 `-3.24%`。
- 月度 Tab：9月~2月，选中蓝胶囊。

### 4.5 列表行（资讯/公告/供求通用）


### 4.6 广告位

- 首页轮播：330px 高、圆角 16px、自动播放 4.2s + 悬停暂停 + 页码圆点；右上角可以带「广告」半透明标识。

## 六、交互 & 质量规则

1. **折叠原则**：列表类核心信息（供求、子分类、供应链接）平铺；长列表（产品卡、文章）可折叠但不可省略。
2. **响应式断点**：`1150px`（三栏→两栏）、`1024px`（行情/资讯单列、名企 2 列、产品卡 3 列）、`760px`（全单栏、菜单折叠汉堡、工具条只留登录注册）。
3. **动效**：滚动显现 `IntersectionObserver` + `cubic-bezier(.16,1,.3,1)`；全站支持 `prefers-reduced-motion`。
4. **对齐铁律**：同行卡片等高、底边齐平；左右分界线跨行对齐（如 1:2 比例行之间统一比例）；grid stretch 拉伸时 flex 列尾部块必须 `margin-top:auto`。
5. **无障碍**：涨跌除颜色外带 `↑/↓` 箭头或正负号；焦点态可见；触控目标 ≥44px。
6. **新页面 Checklist**：引用本文件 token → 复用三段式头部/页脚 → 卡片等高对齐 → 广告位带标识 → 数字 tabular-nums → 响应式三断点 → 移动端检查。
